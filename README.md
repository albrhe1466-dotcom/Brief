## What's New in `v2.1.0-beta`

- **Authentic Claude 4-State `#d9693f` Animations & Official Brief Code Mascot:** Exact 8-frame organic hand-drawn Claude starburst for Starting/Checking, untouched `200×200` 3D Orbiting Dots for Thinking, bold bouncing & pulsing circles for Creating/Finding files, and Anthropic's official Claude Code pixel mascot in Brief Code.
- **New White-on-Black `brief^Ai` Brand Identity:** Crisp white `brief^Ai` logo on pure black fitted across the desktop app, Android launcher, website navbar, and GitHub.
- **Live Touch Screen Typing (Recommended) vs. Keyboard Method:** Highlights exact touch targets on screen and types visibly letter-by-letter on Android tablets & phones, or switch to direct Windows-style keyboard input anytime.
- **Gemini 4 Carbon, 3.8 Flash Fix & Live `</>` Code Execution Cards:** Fast Gemini 3.8 Flash & 4 Carbon routing, centered Extra High thinking, 48 dynamic Claude greetings, OpenAI GPT-6 Work suite, and live `</>` code execution cards.

## Supported AI Providers (Bring Your Own Key)

- **Google Gemini** (`AIza...` / `AQ...`) — Gemini 3.5 Flash-Lite, Gemini 3.8 Flash, Gemini 4 Carbon
- **OpenAI** (`sk-...`) — Auto, GPT-6 Luna, GPT-6.1 Terra, GPT-6.2 Sol, GPT-6.2 Astra
- **Anthropic Claude** (`sk-ant-...`) — Claude Haiku 4.5, Claude Sonnet 4.6, Claude Opus 4.7 & Brief Code (`</>`)
- **OpenRouter** (`sk-or-...`)

Keys are encrypted locally using OS keychain / Windows DPAPI / Android Hardware Keystore (AES-256-GCM) and never leave your device except for requests to your chosen provider.
