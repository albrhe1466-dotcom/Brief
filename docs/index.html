Under The Hood

Technical architecture facts & honest Windows boundaries.

Per-Monitor DPI Normalization + Native Windows OCR

Standard Electron desktop capture or naive pixel guessing breaks on 125%, 150%, or dual-monitor setups. Brief queries every display's logical DIP bounds and physical resolution, maps normalized 0–1000 model coordinates into exact screen pixels, and runs native Windows.Media.Ocr.OcrEngine right in memory.

  • Captures up to 3,840 px wide GDI+ screenshots with an optional coordinate overlay grid.
  • click_text matches on-screen labels using extracted OCR bounding boxes rather than blind guessing.
  • zoom_region crops dense timelines, CAD toolbars, or small buttons before clicking.
norm(0..1000, 0..1000)
  -> dip(display.bounds.x + nx * width, ny * height)
  -> nativePhysical(dip * scaleFactor)
  -> SetProcessDpiAwarenessContext(-4) // Per-Monitor V2

OCR Engine:
  Windows.Media.Ocr.OcrEngine.TryCreateFromUserProfileLanguages()
  Returns line bounding rects + confidence centers

Aligned Mouse Motion, Drag & Art Stroke Primitives

Rather than spawning a slow new PowerShell process for every single click, Brief boots a single long-lived background Win32 P/Invoke input host (src/main/native/winput.ps1) communicating over stdin/stdout JSON lines.

  • Supports adaptive, slow, medium, and fast cursor trajectories plus post-action alignCursorBack.
  • hold_key, mouse_button, drag, and scroll support real hold-and-drag gestures for sliders, timelines, and canvases.
  • draw_art executes smooth multi-point geometric vector strokes for diagrams and artwork.
Host Process:
  powershell.exe -> src/main/native/winput.ps1 (persistent loop)
  user32.dll :: SendInput(INPUT[], cbSize)

Supported Profiles:
  adaptive  -> adjusts ease speed by travel distance
  slow      -> precision drawing & delicate UI targets
  medium    -> balanced everyday workflow speed
  fast      -> rapid repetitive navigation

Zero Plaintext Key Storage + Transparent OS Boundaries

Every API key you paste is encrypted using Electron safeStorage backed by Windows DPAPI (tied to your logged-in Windows user account). Brief never uploads keys to any intermediary server and clearly discloses Windows OS protections.

  • Keys never touch remote analytics, telemetry servers, or unencrypted disk files.
  • Permission Modes: Chat Only, Ask for Permission, and guarded Full Access (permanent deletions always confirm).
  • Honest Windows UIPI Boundary: Non-elevated apps cannot send synthetic input to elevated Administrator windows, UAC prompts, or Secure Desktop.
Storage:
  safeStorage.encryptString(apiKey) -> DPAPI blob on userData
  Legacy migration: no plaintext secret files written

Provider Endpoints Only:
  Gemini     -> generativelanguage.googleapis.com
  OpenAI     -> api.openai.com
  Anthropic  -> api.anthropic.com
  OpenRouter -> openrouter.ai/api/v1

Native Windows Action Center Notifications & Local MCP

Long multi-step builds don't require staring at the chat window. Brief pushes real Windows Toast notifications through Windows Notification Manager when an agent finishes, hits an error, or requests permission, alongside a local MCP bridge on port 3847.

  • Windows Action Center alerts notify you even if Brief is minimized behind Roblox Studio or VS Code.
  • Local MCP Bridge: Auto-discovers connected MCP servers and exposes live workspace tools cleanly on 127.0.0.1:3847.
  • Automatic thought recovery: Preserves and strips malformed thought_signature tool state safely mid-turn.
Windows Toast Pipeline:
  Main Process -> Windows.UI.Notifications.ToastNotificationManager
  Events: task_complete | approval_needed | task_error

Local MCP Bridge:
  http://127.0.0.1:3847/mcp/connect
  Discovers active IDE & creative tool MCP integrations

Questions & Answers

Everything to know before and after downloading.

It is a real compiled Windows executable built with Microsoft .NET Framework 4 (csc.exe / WinForms) and stamped with the Brief icon via rcedit. Clicking any Download button on this site saves Brief-Setup.exe directly to your Downloads folder; running it launches Windows's own native Setup Wizard, downloads brief-package.zip, extracts Brief.exe, creates Desktop & Start Menu shortcuts, and launches Brief into onboarding.
Because Brief-Setup.exe is a community/indie open-source release compiled cleanly via GitHub Actions rather than an expensive commercial EV code-signing certificate, Windows SmartScreen may show "Windows protected your PC" on first run. You can inspect the exact open-source compiler script in scripts/build-installer.js, verify the SHA-256 hash above, click More info → Run anyway, or download the raw brief-package.zip archive directly and extract it anywhere.
Yes. Both this GitHub Pages webpage and the GitHub Releases binary assets (Brief-Setup.exe and brief-package.zip) are hosted 24/7 on GitHub's cloud infrastructure. Any user anywhere can download and install Brief at any time with your local computer completely shut down.
Electron renders only Brief's chat and dashboard window. All actual screen vision, OCR, window management, mouse motion, drags, scrolling, and key presses execute in Brief's Node main process and its persistent Win32 native PowerShell input host (winput.ps1) calling Windows user32.dll SendInput and Windows.Media.Ocr directly at native OS speed.
You can paste a Google Gemini key (AIza... or AQ....), an OpenAI key (sk-...), an Anthropic Claude key (sk-ant-...), or an OpenRouter key (sk-or-...). Slide 3 detects the provider instantaneously, validates the key against the provider API, saves it encrypted with Windows DPAPI, and brings you directly into Brief.
All API keys are sealed locally via Electron safeStorage (Windows DPAPI) inside your local Windows user profile, and chat history stays in local JSON files under your userData folder. Nothing is synced to Brief's website or any third-party backend.
Press Ctrl + Alt + Q globally anywhere in Windows (even while another full-screen app is focused) or click the red STOP control in Brief's floating status overlay to abort automation immediately.
Windows User Interface Privilege Isolation (UIPI) blocks standard user-level processes from injecting synthetic SendInput keystrokes or clicks into elevated Administrator windows or the Windows Secure Desktop. For security, Brief runs per-user without demanding Administrator elevation and documents this Windows boundary openly.
